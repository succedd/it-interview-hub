# IT面试题库管理系统

## 项目简介

纯静态、无需后端、无需数据库服务的IT各岗位面试题库管理网站。覆盖21大技术领域、100+技术子分类、所有主流IT岗位的面试题。

## 核心功能

- **技术体系导航**：按IT技术演进历史顺序组织技术分类
- **岗位体系导航**：按行业发展阶段组织所有IT岗位
- **题目浏览与搜索**：支持多维度筛选、模糊搜索、关键词高亮
- **收藏与历史**：收藏题目、自动记录浏览历史
- **模拟面试**：按岗位和年限生成面试题，计时作答，掌握程度标记
- **AI智能生成**：通过DeepSeek Harness API自动生成面试题
- **批量导入导出**：支持Excel/CSV/JSON/Markdown格式导入导出
- **全量备份恢复**：一键导出JSON备份，支持合并恢复和全量覆盖
- **管理员模式**：本地密码认证，完整的题目/分类/岗位管理功能
- **亮色/暗色主题**：支持亮色、暗色、跟随系统三种模式

## 技术栈

- **前端框架**: Vue 3 (CDN)
- **本地存储**: IndexedDB (Dexie.js)
- **模糊搜索**: Fuse.js
- **Markdown渲染**: marked.js
- **AI接口**: DeepSeek Harness API
- **部署方式**: GitHub Pages / 本地直接打开

## 使用方式

### 直接使用

打开 `index.html` 即可使用，所有数据保存在浏览器本地。

### 部署到GitHub Pages

1. 将本项目上传到GitHub仓库
2. 在仓库设置中开启GitHub Pages
3. 选择main分支的根目录作为源

## 管理员功能

1. 点击右上角「管理员」按钮
2. 首次使用设置管理员密码
3. 登录后即可使用完整的题库管理功能
